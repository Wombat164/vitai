- **A field name does not identify a dataset** (#402). The first version of
  `Vitai.overlap_calibration` found the dataset by searching for one carrying
  the field name and taking the first hit. `distance_km` is on `daily` AND on
  `sessions`, so asking about two GPS sources measured the daily summaries
  instead and reported a refusal over an overlap of a hundred-odd runs that
  was sitting right there. The caller names the dataset.

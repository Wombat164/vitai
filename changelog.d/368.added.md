- Added `Vitai.plan()` (#368), a third narrative-capture verb beside `claim()`
  and `said()`: a plan is DECIDED rather than ACQUIRED, so it stamps `plans`'
  own provenance vocabulary (`set_by`, defaulting to `athlete`) instead of
  `claim()`'s acquisition stamp (`capture`, `read_by`, `source`), which
  `plans` does not carry. `vitai plan` on the CLI and the `plan` MCP tool land
  in the same change (P9).
- `claim(dataset="plans", ...)` now raises its own error naming `plan()` as
  the way in, instead of falling through to `append_many`'s generic "unknown
  key(s) for plans: capture, read_by, source" - which named three internal
  fields and no way forward.

- A gate on the shipped example's dataset coverage. `generate_demo.py --check`
  byte-compares the demo against its generator, so it cannot drift - but
  nothing checked whether the generator had heard of a dataset at all. Adding
  one and writing its demo file by hand produced drift on a file nothing could
  regenerate, under a message advising exactly the fix that does not work.
- Every dataset is now either written by the generator or listed as
  deliberately absent with a reason, and the register has back-pressure in both
  directions: an entry that gains a writer must leave, and one naming a dataset
  the schema no longer has must go too.

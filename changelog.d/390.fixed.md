- **A relay that composes its own name into a vendor's string no longer
  breaks the match** (#390). Moving eight MyFitnessPal export strings under
  `myfitnesspal` reasoned that the suffixed spelling was a hand-added
  provenance annotation and that "the vendor's export does not carry it and
  nothing here composes one". Fitbit does: when a third-party app writes an
  exercise, the Fitbit account export records the attribution INSIDE
  `activityName`, so a real archive holds `walking, general (MyFitnessPal)`
  where the direct export holds `walking, general`. The change therefore did
  not swap a synthetic spelling for a real one - it swapped one real spelling
  for another, and every Fitbit-relayed MFP session would have reverted to
  `other` on the next re-import.
- **The rule is data-driven, not a regex over a suffix**, which is what the
  original change rightly wanted to avoid. A trailing parenthesised group is
  removed only when its contents RESOLVE TO A DECLARED SOURCE, so it can only
  ever reach an entry the registries already name. Two of the registry's own
  alias strings end in parentheses that are part of the activity name -
  `running (jogging), 9 mph (6.5 min mile)` and `bicycling, 12-14 mph,
  moderate (cycling, biking, bike riding)` - and both still resolve, which a
  blind suffix strip would have broken worse than the bug it fixed.
- **Tried last, so it can never reinterpret a value a registry declares.** A
  widening that changes what an existing accepted string means is not a
  widening. The sources registry is exempt from the rule outright: it would
  recurse, and a source name carries no attribution because the relay IS a
  source. A declined proposal stays declined through the relayed form.
- Found by a downstream record's engine pin failing to move from contract 40
  to 47. Its importer test pinned these aliases specifically so they could not
  quietly revert, and it fired. The pin was reverted rather than updated,
  which is what a pin is for: it means "checked against", and this had not
  passed.

- The README's Status line stated a fixed contract number ("contract 27; contract
  28 is unreleased") that had drifted eighteen contracts behind
  `CONTRACT_VERSION`, because nothing checked prose outside the migration
  table. The number is removed from the Status line; the migration table
  stays the single place a contract number lives, and a new test asserts no
  other prose in README.md claims one (#369).
- That test's pattern only matched `contract N` with a literal space, so a
  hyphenated form like this repo's own "a contract-1 reader" (`wiki/content/
  explanation/platform.md`) would have walked straight past it. Widened to
  match case-insensitively with an optional space or hyphen between the word
  and the number, so `CONTRACT 27`, `contract-27` and `contract27` are all
  caught too (#369).

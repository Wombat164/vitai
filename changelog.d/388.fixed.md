- The medical-boundary gate scans `tests/`. The repo is public, so a class (c)
  claim in a test file is exactly as published as one in `src/`, and `tests/`
  was outside the gate's `SURFACE` entirely. #387 wrote one: a generator comment
  explaining a persona selection by applying a category to two named people,
  inside the change that forbade doing so, with the compliant wording already in
  use elsewhere in the same diff. Every control was green.
- Use versus mention, drawn on Python's own grammar rather than on a directory
  exemption. Adding `tests` to `SURFACE` alone reports 62 findings, and nearly
  all are the controls' own material - `test_boundary_gate.py` must contain "see
  a doctor" to prove the directive family fires. So inside `tests/` a string
  literal is the INPUT a test checks and is not scanned, while a comment or a
  docstring is the file talking in its own voice and is. That is the difference
  between quoting a violation and asserting one, and it takes 62 to 14.
- Docstrings are voice, not data, even though the parser calls them literals.
  `src` and `examples` are deliberately NOT in `TEST_MATERIAL`: a string literal
  there is what the product SAYS - `safety.ACUTE`'s messages are string literals
  and they are the most important thing this gate reads.
- Consecutive comment lines are one paragraph. Emitting each separately cut a
  wrapped sentence into fragments and a claim spanning two lines matched
  nothing, which is how the first cut of this change passed its own fixture.
- 108 non-Python files under `tests/` come into scope whole, including the 77
  persona markdown files - `WORLD.md`, `LIES.md`, `PROFILE.md` are narrative
  prose about a person, which is the likeliest place in the repo for a category
  claim. None reports anything today.
- The 14 survivors are registered in the existing `EXEMPT` register, per file,
  per sentence hash, each with the reason it quotes - the same mechanism
  `docs/medical-boundary.md` already uses for the same shape, not a new one. A
  new control refuses two exemptions sharing a reason, so the next entry has to
  be written rather than pasted.

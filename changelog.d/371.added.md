- `validate()` now catches an unpinned `weight` or `measurements` row rather
  than only leaving `protocol` readable and unread: where a dataset's own
  rows have named a protocol slug, every row of that dataset dated on or
  after that slug's earliest declaration and carrying no `protocol` is now an
  advisory, aggregated into one line naming the count and the date span
  rather than one line per row. A dataset that has never named a protocol
  stays silent - a `protocols` row does not say which dataset it governs, so
  "a protocol applies here" is derived from the dataset's own usage, never
  assumed from the mere existence of a `protocols` row for something else.
  Advisory, never a refusal: the file is append-only, most weight rows in a
  real record predate the practice, and a validator that cannot pass on a
  real record gets switched off (#371).

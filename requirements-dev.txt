# ecosystem reads requirements files in the directory it is pointed at, so
# these get bumped and reviewed like everything else - which was the other
# half of the complaint. It does NOT read `pip install` lines inside a
# workflow, which is why the old shape could never have been noticed.
#
# `scripts/pin_gate.py` holds this file and every place that states it to each
# other, and runs in `pytest` as well as in CI.

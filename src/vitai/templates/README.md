# health (vitai content repo)

Personal health, fitness and nutrition record. **Keep this repo PRIVATE.**

Built on [vitai](https://github.com/Wombat164/vitai): plain-text record,
deterministic engine, LLM coaching via skills.

## Files

| File | What it is | Changes |
|---|---|---|
| `profile.md` | Full snapshot: physiology, history, constraints, motivations | Slowly |
| `plan.md` | The working plan. Start at section 0, open actions | Often |
| `CLAUDE.md` | Operating instructions for an AI assistant picking this up | Rarely |
| `vitai.toml` | Your thresholds (rate phases, HR caps, floors, gates) | Rarely |
| `data/*.jsonl` | Append-only observations. **Never edit a line** - supersede it | Weekly |
| `derived/` | Generated by `vitai build`. Disposable, always rebuildable | On build |

## Weekly, about 3 minutes

```bash
# append the week's lines to data/*.jsonl, then:
vitai validate && vitai build
git add -A && git commit -m "week of $(date +%Y-%m-%d)" && git push
```

Read `derived/weekly.md` for the rate check and tripwires.

## The three rules

1. **Never edit a `.jsonl` line.** Append a correction with `supersedes`.
2. **Never hand-edit `derived/`.** Delete and rebuild instead.
3. **Sparse and continuous beats rich and abandoned.** If the weekly cost
   exceeds three minutes, cut fields - do not skip weeks. If motivation dips
   to nothing, `weight.jsonl` alone still carries the primary goal.
